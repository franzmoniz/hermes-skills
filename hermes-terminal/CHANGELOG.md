# Changelog - Hermes's Terminal

## 0.1.0 - 2026-11-11
### Added
- First version: typing `hermes` always opens the same conversation, "Hermes's Terminal", pinned in the
  Hermes app, with a 3-line recap of where you stopped (optional, you choose the model).
- `hermes-new` opens a separate new conversation.
- Long conversations that Hermes compresses ("Hermes's Terminal #2", "#3") are followed automatically.
- Works alone. With Hermes Device Sync installed, the same conversation continues on all your devices.
- (Before this skill existed, this was part of Hermes Device Sync up to version 0.6.0.)
