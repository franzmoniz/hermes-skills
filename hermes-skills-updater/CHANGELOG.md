# Changelog - Hermes Skills Updater

## 0.1.0 - 2026-11-11
### Added
- First version: at the start of each session, checks this repository for updates of the skills you
  installed from it, shows what was added / changed / fixed / removed, and updates only the ones you
  say yes to (backup first). With Hermes Device Sync, your answer applies to all your devices.
